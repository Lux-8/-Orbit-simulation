# Orbit Simulation

Учебный проект на Python для моделирования движения небесных тел и визуализации орбит.

## Цели проекта

- Научиться работать с библиотеками Python для научных вычислений и визуализации.
- Освоить создание графиков и анимаций.
- Применить физические и астрономические формулы на практике.
- Изучить основы моделирования орбитального движения.
- Научиться проверять результаты вычислений и оценивать точность модели.
